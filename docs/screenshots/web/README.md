# Web deployment screenshots

Captured 2026-11-23 on iOS Safari against the live Firebase Hosting
deployment at https://family-pulse-sznzoj.web.app — no install, no
emulator, no desktop. These verify the browser build of the app that
reviewers are asked to open.

| File | What it shows |
|---|---|

| `web_mobile_create_family.png` | Create-a-family form rendering correctly at phone width |
| `web_mobile_family_created.png` | Family created; invite code returned and copyable |
| `web_mobile_home.png` | Pulse home: today's schedule, upcoming count, quick navigation |
| `web_mobile_drawer.png` | Navigation drawer — Calendar, Family, Groups, Free time, Analytics |

The invite code visible in `web_mobile_family_created.png` belongs to a
throwaway test family and is not used for any seeded demo account.
